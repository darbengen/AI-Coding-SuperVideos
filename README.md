## 下载完整原始 ZIP

原始 ZIP 大小为 2,566,359,331 字节（约 2.39 GiB），超过 GitHub Release 单附件上限，按原始字节切成两段：

- [AI-Coding-SuperVideos.zip.001](https://github.com/darbengen/AI-Coding-SuperVideos/releases/download/archive-20261012/AI-Coding-SuperVideos.zip.001)（1,400,000,000 字节）
- [AI-Coding-SuperVideos.zip.002](https://github.com/darbengen/AI-Coding-SuperVideos/releases/download/archive-20261012/AI-Coding-SuperVideos.zip.002)（1,166,359,331 字节）

将两段下载到同一个文件夹，然后合并即可得到与输入完全一致的 ZIP。

**macOS / Linux：**

```sh
cat AI-Coding-SuperVideos.zip.001 AI-Coding-SuperVideos.zip.002 > AI-Coding-SuperVideos.zip
shasum -a 256 AI-Coding-SuperVideos.zip
```

**Windows（命令提示符）：**

```bat
copy /b AI-Coding-SuperVideos.zip.001+AI-Coding-SuperVideos.zip.002 AI-Coding-SuperVideos.zip
certutil -hashfile AI-Coding-SuperVideos.zip SHA256
```

```text

```
